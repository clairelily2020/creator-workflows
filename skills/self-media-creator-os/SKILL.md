# Self-Media Creator OS

Use this skill to turn practice into publishable content.

## Source Material

- A GitHub repo the user built, installed, studied, or rejected
- AI product/model/API updates
- Workflow changes, automations, and skills
- Screenshots, debugging notes, setup mistakes
- Learning logs and personal reflections

## Platform Fit

| Platform | Best format |
|---|---|
| X | short post or thread |
| LinkedIn | professional reflection |
| Xiaohongshu / Rednote | visual card set |
| WeChat Official Account | long-form essay |
| Jike | casual Chinese observation |
| Bluesky | lightweight tech note |

## Workflow

1. Extract the real learning from the source.
2. Write one core point.
3. Decide which platforms fit. Do not force every platform.
4. Draft each platform natively.
5. Suggest visual assets if they improve clarity.
6. Run privacy and AI-writing checks.
7. Prepare a publishing checklist.

## Output Format

```text
Source:
What happened:
What I learned:
Core point:
Proof:

X:
LinkedIn:
Xiaohongshu:
WeChat:
Jike:
Bluesky:

Visual asset plan:
Publishing checklist:
Risk notes:
```

## Quality Gates

- Do not invent experience the user did not have.
- Do not copy one paragraph across all platforms.
- Do not publish secrets, private screenshots, customer data, or internal strategy.
- If discussing current AI features, verify facts before drafting.

# creator-workflows

给创作者和独立开发者用的 skill：漫画和短视频故事、短剧、多平台个人内容、长期计划，外加一个"新 skill 或新工具值不值得装"的判断关卡。

[English](README.md)

| Skill | 做什么 |
|---|---|
| [comic-story-pipeline](skills/comic-story-pipeline/SKILL.md) | 把粗糙的漫画或短视频想法变成可以开工的故事包 |
| [comic-review](skills/comic-review/SKILL.md) | 开工前检查故事、分镜和画面质量 |
| [comic-preflight](skills/comic-preflight/SKILL.md) | 发布前检查漫画或视频成品 |
| [story-drama-creator-os](skills/story-drama-creator-os/SKILL.md) | 短剧的一句话梗概、人物表、分集弧线和场景卡 |
| [self-media-creator-os](skills/self-media-creator-os/SKILL.md) | 把项目、AI 动态和笔记改写成 X、LinkedIn、小红书、公众号、即刻、Bluesky 的内容 |
| [long-term-plan](skills/long-term-plan/SKILL.md) | 把目标拆成里程碑、任务、依赖和排期 |
| [workflow-install-gate](skills/workflow-install-gate/SKILL.md) | 装新 skill 或工具前先判断跳过、更新、新建还是安装，带测试提示和回滚办法 |

安装：把 `skills/` 下的目录拷进 `~/.claude/skills/` 或 `~/.codex/skills/`。

搭配使用：第三方的 [Seedance 产品视频提示词](https://github.com/op7418/Seedance-Product-Video)（作者 op7418）。B2B 市场相关的内容在 [b2b-growth-kit](https://github.com/clairelily2020/b2b-growth-kit)。

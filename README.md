# creator-workflows

Skills for creators and builders: comics and short-video stories, short drama, personal publishing across platforms, long-term planning, and a gate for deciding whether a new skill or tool is worth installing.

[中文说明](README.zh-CN.md)

## Skills

| Skill | What it does |
|---|---|
| [comic-story-pipeline](skills/comic-story-pipeline/SKILL.md) | Turns a rough comic or short-video idea into a production-ready story package |
| [comic-review](skills/comic-review/SKILL.md) | Reviews story, panels and visual quality before production |
| [comic-preflight](skills/comic-preflight/SKILL.md) | Checks a comic or video package before publishing |
| [story-drama-creator-os](skills/story-drama-creator-os/SKILL.md) | Logline, character grid, episode arc and scene cards for short drama |
| [self-media-creator-os](skills/self-media-creator-os/SKILL.md) | Turns repos, AI updates and notes into posts for X, LinkedIn, Xiaohongshu, WeChat, Jike and Bluesky |
| [long-term-plan](skills/long-term-plan/SKILL.md) | Goals into milestones, tasks, dependencies and a schedule |
| [workflow-install-gate](skills/workflow-install-gate/SKILL.md) | Decide skip, update, create or install before adding a skill or tool, with test prompts and a rollback path |

Collections: [self-media-creator-os](collections/self-media-creator-os.md), [story-drama-creator-os](collections/story-drama-creator-os.md).

## Install

```bash
git clone https://github.com/clairelily2020/creator-workflows.git
cp -R creator-workflows/skills/* ~/.claude/skills/     # Claude Code
cp -R creator-workflows/skills/* ~/.codex/skills/      # Codex
```

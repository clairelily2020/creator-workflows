# Self-Media Creator OS

This collection is for builders and creators who want to turn AI practice into regular public writing.

## Source Material

- GitHub repos you built, installed, rejected, forked, or studied
- AI product updates and model/API changes
- Codex, Claude Code, Cursor, or agent workflow experiments
- Debugging notes, setup mistakes, screenshots, and lessons
- Reading notes and personal learning logs

## Platform Routing

| Platform | Best use |
|---|---|
| X | fast observations, short threads, build-in-public |
| LinkedIn | professional lessons and workflow summaries |
| Xiaohongshu / Rednote | visual learning cards |
| WeChat Official Account | long-form Chinese essays |
| Jike | casual Chinese observations |
| Bluesky | lightweight tech notes and links |

## Example Prompt

```text
Use self-media-creator-os.
Source: https://github.com/{owner}/{repo}
I installed this repo and want to explain what I learned.
Create drafts for X, LinkedIn, Xiaohongshu, WeChat, Jike, and Bluesky.
Also suggest what visual cards I should make.
```
